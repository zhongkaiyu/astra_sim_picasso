# congestion_aware Usage

This directory batch-runs analytical ASTRA-sim workloads and stores results in CSV/SQLite caches.

## Layout
- `configs/`: ASTRA-sim config files (JSON).
- `trace_configs/`: optional trace generation configs (JSON).
- `bulk_run_configs.py`: batch runner entrypoint.
- `cache_db_test/`: default result cache (CSV/SQLite).
- `csv_to_sqlite.py`: CSV to SQLite converter.

## Config files (`configs/*.json`)
Common fields (example):
```
{
  "workload_dir": "{PROJECT_DIR}/examples/workloads/all_reduce_scaling/all_reduce_2gpus",
  "workload_base": "all_reduce_2gpus",
  "comm_group": "{PROJECT_DIR}/examples/workloads/all_reduce_scaling/all_reduce_2gpus/all_reduce_2gpus.json",
  "system": "{EXAMPLE_DIR}/system/native_collectives/ring2_H100.json",
  "network": "{EXAMPLE_DIR}/network/analytical/FullyConn_2gpus_H100.yml",
  "remote_memory": "{EXAMPLE_DIR}/remote_memory/analytical/no_memory_expansion.json",
  "output_dir": "{PROJECT_DIR}/output/scaling_test/comm_all_reduce_2gpus_fc_ring",
  "log_file": "comm_all_reduce_2gpus_fc_ring.log"
}
```

Placeholders:
- `{PROJECT_DIR}`: project root
- `{EXAMPLE_DIR}`: `{PROJECT_DIR}/examples`

### Physical vs. logical topology (examples)
Physical topology is encoded by the `network` file; logical topology is encoded by the `system` file.
```
{
  "system": "{EXAMPLE_DIR}/system/native_collectives/ring2_H100.json",
  "network": "{EXAMPLE_DIR}/network/analytical/FullyConn_2gpus_H100.yml"
}
```

### Definitions
- Physical topology (`network`): the interconnect graph and link characteristics (e.g., fully-connected, mesh2d, torus), defined in `examples/network/analytical/*.yml`.
- Logical topology (`system`): the collective algorithm/topology used by ASTRA-sim (e.g., ring), defined in `examples/system/native_collectives/*.json`.

## bulk_run_configs.py usage

1) Run a subset of configs
```bash
python3 bulk_run_configs.py \
  --configs-dir configs \
  --pattern "comm_all_reduce_*.json"
```

2) Force re-run (ignore cache)
```bash
python3 bulk_run_configs.py \
  --configs-dir configs \
  --pattern "comm_all_reduce_*.json" \
  --force-run
```

3) Generate trace (optional)
```bash
python3 bulk_run_configs.py \
  --gen-trace \
  --trace-configs-dir trace_configs \
  --trace-pattern "*.json"
```

## How to generate traces

Option A: Use JSON files in `trace_configs/` (recommended, explicit parameters)

Example `trace_configs/*.json`:
```
{
  "output_dir": "{PROJECT_DIR}/examples/workloads/et_trace",
  "output_name": "decode_bypass_dp16",
  "model_type": "qwen_decode_bypass",
  "dp": 16,
  "tp": 1,
  "pp": 1,
  "batch": 64,
  "seq": 1024,
  "tpsp": true
}
```

Run:
```bash
python3 bulk_run_configs.py \
  --gen-trace \
  --trace-configs-dir trace_configs \
  --trace-pattern "*.json"
```

Option B: Generate directly from `configs/*.json` (no separate trace configs)
```bash
python3 bulk_run_configs.py \
  --gen-trace \
  --configs-dir configs \
  --pattern "comm_all_reduce_*.json"
```
Note: the script reads `workload_dir` / `workload_base` and parses `tp/dp/pp` from the config file name.

### Trace model options
When generating traces, `model_type` supports these values (inferred by name or set explicitly):
- `qwen_decode_bypass_tp16`
- `qwen_decode_bypass`
- `qwen_decode_attention`
- `qwen_forward_only_bypass`
- `qwen_forward_attention`
- `moe`
- `dense`

### Generate communication primitive traces
The communication traces referenced by `comm_*` configs are generated by:
`tests/rt_template/inputs/workload/gen_chakra_traces.py`.

Generate the default 16-GPU traces (matches existing configs):
```bash
cd {PROJECT_DIR}/tests/rt_template/inputs/workload
./gen.sh
```

Or run the generator directly with custom parameters:
```bash
python3 {PROJECT_DIR}/tests/rt_template/inputs/workload/gen_chakra_traces.py \
  --npus 16 \
  --comm_size 1048576 \
  --out_dir {PROJECT_DIR}/tests/rt_template/inputs/workload/comm_primitive_traces_16gpu
```

Outputs will be written to `comm_primitive_traces_16gpu/<op>/chakra_trace.*`,
which are referenced by `comm_*` configs via `workload_dir` + `workload_base`.

4) Custom cache output (optional)
```bash
python3 bulk_run_configs.py \
  --configs-dir configs \
  --pattern "*.json" \
  --csv cache_db_test/results_cache.csv \
  --db cache_db_test/results.sqlite
```

## CSV to SQLite
```bash
python3 csv_to_sqlite.py \
  --csv cache_db_test/results_cache.csv \
  --db cache_db_test/results.sqlite
```
