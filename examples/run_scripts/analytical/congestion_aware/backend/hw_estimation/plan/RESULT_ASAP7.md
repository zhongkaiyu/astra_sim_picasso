# AMMA HMP_REO — ASAP7 综合估算结果(N7→N4 实测缩放)

**日期**: 2026-05-26
**方法**: Yosys + ASAP7 PDK 真实标准单元综合 → TSMC N7→N4 研究级缩放因子 → 4nm 等效
**数据来源**: 全部组件面积来自 ASAP7 7nm 综合(A/C/D/E/F)或 CACTI(B)或物理 IP reference(G/H/K)

## 1. 核心 insight:"4nm" 是营销名,不是真正新节点

> 研究结论(2026-05 多源核实,见 §6 引用):
> **TSMC N4 是 N5 家族的精炼成员**(design-rule 与 N5 兼容,N4P 比 N5 仅 +6% 密度),**不是真正的新一代节点**。真正的代际跳跃是 **N7→N5**。
>
> 因此 ASAP7(predictive 7nm)→ 4nm 的缩放 = **N7→N5(真实大跳) × N5→N4(小幅精炼)**。

这直接影响缩放因子:不能用"每代 0.7×"的旧 Dennard 假设,因为:
1. **N7→N5 逻辑密度实测仅 1.518×**(不是 TSMC 营销的 1.84×)
2. **N5→N4 只 +6%**
3. **Vdd 从 N7 到 N4 基本不变(~0.75-0.8V)**——Dennard scaling 已死,漏电不随面积线性下降
4. **SRAM 缩放停滞**——N7→N5 只 1.35×(vs 逻辑 1.84×)

## 2. N7 → N4 缩放公式(研究级,带引用)

### 2.1 逐指标缩放因子(乘以 7nm 值得 4nm 值)

| 指标 | N7→N5 | N5→N4 | **N7→N4 复合** | 推导 |
|------|-------|-------|---------------|------|
| **逻辑面积** | ÷1.518 (=0.659) | ÷1.06 (=0.943) | **0.62×** | 密度 1.518×1.06 = 1.609× → 1/1.609 |
| **SRAM 面积** | ÷1.35 (=0.741) | ~1.0 (停滞) | **0.74×** | SRAM 1.35× 远弱于逻辑,N4 无改善 |
| **动态功耗** (iso-freq) | 0.70 (−30%) | ~0.97 (N4P +22%效率,非线性叠加) | **0.68×** | TSMC −30% + N4P 精炼 |
| **漏电/静态** | ~0.85 | ~0.94 | **0.80×** | Vdd 平台化,保守(不随面积) |
| **延迟** | 0.85 (+15%) | 0.94 (+11%) | **0.80×** | iso-power 速度提升 |

### 2.2 关键数据点(实测,非营销)

| 节点 | 逻辑密度 (MTr/mm²) | SRAM bitcell (µm²) | Vdd (V) | 来源 |
|------|-------------------|-------------------|---------|------|
| **N7** (H240g57 2-fin) | 90.64 | 0.027 | 0.75-0.80 | Angstronomics (A14/A15 teardown) |
| **N5** (H210g51 2-fin) | 137.6 (1.518× N7) | 0.021 (1.35× N7) | ~0.80 | Angstronomics + ISSCC 2020 |
| **N4/N4P** | ~146 (1.06× N5) | ~0.021 (~flat) | ~0.75-0.80 | TSMC N4P 官方 +6% |

### 2.3 为什么不用 TSMC 营销的 1.84×

TSMC 官方说 N5 是 N7 的 "1.8× logic density",但那是**混合 track 高度的最佳值**。真实芯片(Apple A14/A15 SEM 拆解,System Plus Consulting)apples-to-apples 2-fin 对比是 **1.518×**。我们用实测值 0.62×(保守),营销值 1.84×1.06=1.95× → 0.51× 仅作上界。

### 2.4 代码实现

```python
SCALE_7NM_TO_4NM = {
    "area_logic": 0.62,   # 1 / (1.518 × 1.06)   ← A/C/D/E/F
    "area_sram":  0.74,   # 1 / 1.35 (停滞)        ← (B 实际走 CACTI,此值备用)
    "power":      0.68,   # −32% iso-freq dynamic
    "leakage":    0.80,   # Vdd 平台,保守
    "delay":      0.80,
}
```

## 7. ASAP7 局限(诚实标注)

| 限制 | 影响方向 | 量级 |
|------|---------|------|
| RTL 简化(无 DFT/BIST/scan) | 数字面积偏小 | ~2-3× under |
| 无 place&route(无 routing congestion) | 数字面积偏小 | ~1.5× under |
| ASAP7 predictive(非真实流片) | 标准单元偏理想 | ~1.2× under |
| 2 GHz 流水级未显式建模 | 时序闭合需更多 FF | ~1.5× under |
| 单 corner (TT/RVT) | 无 SS/FF 边界 | ±10% |
| N7→N4 复合因子(派生估计) | area/power | ±10% |

**总体**:数字逻辑(A/C/D/E/F)是 **RTL 综合下限**;真实 4nm AMMA 数字逻辑应为本结果 × 2-4 = 2-4 mm²。但因 logic die 被 K(HBM PHY)+ G(D2D PHY)主导(87%),数字逻辑低估对 logic die 总数(32 mm²)影响 < 10%。
